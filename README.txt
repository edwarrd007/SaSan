SaSaN Security Tool - FINAL

Run:
  1. Create/activate your Python virtual environment.
  2. Run: run.bat
  or: python windows_admin_tool.py

Music Player:
  - SCAN BASE scans only the application BASE folder (the folder containing windows_admin_tool.py).
  - SCAN FOLDER lets you choose any folder and recursively scans it.
  - New tracks are APPENDED to the existing music library and duplicates are ignored.
  - Supported extensions are defined by MUSIC_EXTENSIONS in windows_admin_tool.py.

Assets:
  - assets/sasan_logo.svg is the application logo/icon.
  - assets/icons/ contains section and action icons.
